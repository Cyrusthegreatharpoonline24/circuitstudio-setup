## 💬 Frequently Asked Questions

**Q: The installer says I need administrator rights. What do I do?**
A: Right-click the installer file and select “Run as administrator.” Enter your admin password if prompted.

**Q: Can I install this on a Mac?**
A: This setup is for Windows only. Mac users may need to use Boot Camp or a virtual machine.

**Q: How do I uninstall CircuitStudio?**
A: Go to Control Panel > Programs > Uninstall a program, find CircuitStudio, and click Uninstall.
