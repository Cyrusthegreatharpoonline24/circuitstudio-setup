## Download & Install

> Setup notes for **Altium CircuitStudio** on Windows 10/11 (64-bit). Run the installer as Administrator.

### Quick steps

1. Download the latest Windows build for your edition
2. Save the file to a local folder you can find later
3. Run the setup **as Administrator**
4. Enter your license key when prompted
5. Restart if the installer asks — then launch **Altium CircuitStudio** from the Start menu

## What you can use it for

- Schematic capture and PCB layout editing
- Component libraries and design rule checks
- SPICE simulation and board verification
- Gerber and drill file export for fabrication
- Multi-layer routing and copper pour tools
